# CH PROJECT — сайт

Продающий сайт для CH PROJECT: заборы, ворота, навесы и металлоконструкции под ключ в Рязанской области. Цель сайта — заявки и контакты клиентов, а не просто рассказ о компании.

## Важная техническая оговорка

Изначально запрашивался стек Next.js/React/TypeScript. Сайт собран как **статический HTML/CSS/JS** (без сборки и npm-зависимостей на фронтенде), потому что в этой среде недоступен интернет для установки пакетов. Технически и по продукту это не ограничение: сайт полностью рабочий, быстрый, адаптивный, с калькулятором, формами и SEO-разметкой. Если позже понадобится перевести его на Next.js/React — структура (партиалы шапки/футера, единый CSS, единый конфиг цен `js/products.js`) переносится почти один в один, это отдельная, недолгая задача для разработчика.

## Что создано

1. **Дизайн** — тёмная графитовая тема, один акцентный цвет (тёплый металлический оранжевый), заголовочный шрифт Unbounded + текстовый Manrope. Премиальный минимализм без «шаблонности».
2. **Страницы**:
   - `index.html` — главная (Hero → преимущества → услуги → калькулятор → портфолио → почему мы → как работаем → цены → спецусловия → отзывы → FAQ → финальный CTA)
   - `zabory.html`, `vorota.html`, `navesy.html`, `metallokonstrukcii.html` — страницы услуг с калькулятором и FAQ
   - `calculator.html` — отдельная страница калькулятора
   - `portfolio.html` — портфолио с фильтрами по категориям
   - `contacts.html` — контакты и форма заявки
   - `privacy.html` — заглушка политики конфиденциальности
3. **Калькулятор** («Предварительный расчёт») — тип ограждения, длина, высота, калитки, ворота, автоматика, демонтаж, тип грунта. Все цены вынесены в `js/products.js` — единственное место, где нужно менять цены.
4. **Формы заявки** — с чекбоксами услуг, загрузкой фото участка, UTM-метками, отправкой на `/api/lead`.
5. **AI-консультант (demo)** — плавающая кнопка с чат-виджетом. Отвечает по сценарию, **не называет цены**, подводит к калькулятору/заявке. Готов к замене на реального AI-агента.
6. **Аналитика** — точки для Яндекс.Метрики и GA4, событие `trackEvent()` уже расставлено на: открытие/заполнение/завершение калькулятора, клик «Позвонить», клик Telegram, отправку заявки, загрузку фото, просмотр портфолио.
7. **Backend-заглушка** (`api/server.js`) — принимает заявки, сохраняет их в файл, готов к отправке в Telegram и CRM.
8. **SEO** — Title/Description/H1/H2 под запросы вида «заборы Рязанская область», «забор из профнастила Рязань» и т.д. на каждой странице, без переспама.
9. **Мобильная версия** — крупные кнопки, фиксированная нижняя CTA-панель с кнопкой звонка и «Рассчитать стоимость».

## Что вам нужно заменить перед запуском

- **Телефон** — сейчас `+7 000 000-00-00` во всех местах (шапка, футер, sticky CTA, контакты). Проще всего заменить через `grep -rl "70000000000" .` и `grep -rl "000 000-00-00" .`.
- **Telegram/VK-ссылки** — сейчас `href="#"` с атрибутом `data-telegram-link` (шапка/футер/контакты).
- **Фотографии** — все изображения сейчас плейсхолдеры с подписью «Демонстрационное изображение» (Hero и карточки портфолио). Замените `<div class="img-ph">…</div>` на `<img src="/img/ваше-фото.jpg" alt="…">` в соответствующих HTML или в `content_blocks.py` (если планируете пересобирать сайт).
- **Портфолио** — сейчас 9 demo-проектов с пометкой «пример оформления проекта» в `content_blocks.py` (`PORTFOLIO_ITEMS`). Замените на реальные объекты, когда они появятся.
- **Отзывы** — сейчас заглушки в `content_blocks.py` (`reviews_block`). Добавляйте реальные отзывы (текст, имя, дата, фото) по мере поступления.
- **Цены** — все значения в `js/products.js` — плейсхолдеры (`pricePerM`, `price` и т.д.). Замените на реальные цены компании.
- **Раздел «Стоимость» на главной** — значения «от ХХХ ₽» в таблице (`build_pages.py`, функция `build_home`) — замените на ориентировочные цены, когда согласуете их.
- **Гарантия / скидки** — намеренно оставлены без конкретных цифр («условия уточняются в договоре» / без указания процента), как и просили. Впишите цифры, когда определитесь.
- **Домен в метатегах** — `https://chproject.ru` в `<link rel="canonical">` (генерируется в `build.py`, функция `head()`) — замените на реальный домен.

## Какие API/ключи нужно подключить

Ничего из перечисленного ниже не вставлено в код в виде реальных значений — везде плейсхолдеры, ключи задаются через `.env` (backend) или напрямую в `<script>` тегах (аналитика, т.к. эти ID не секретны и всегда видны в исходном коде сайта):

- **Яндекс.Метрика** — счётчик ID → `window.YM_COUNTER_ID` в конце каждой HTML-страницы, плюс сам код счётчика Метрики (вставляется в `<head>`, см. комментарий `<!-- Яндекс.Метрика -->`).
- **Google Analytics (GA4)** — при необходимости, аналогично, тег `gtag.js` в `<head>`.
- **Telegram Bot API** — `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в `.env` для `api/server.js`.
- **CRM** — `CRM_API_URL`, `CRM_API_KEY` в `.env`, когда определитесь с системой (amoCRM, Bitrix24 и т.д.) — точка интеграции обозначена комментарием `TODO` в `api/server.js`.

## Как разместить сайт в интернете

Сайт статический — подходит любой простой хостинг:

1. **Vercel / Netlify** (проще всего): загрузите папку `chproject/` (без `api/`, если не разворачиваете backend там же) как статический сайт — команда сборки не нужна, корень публикации — сама папка.
2. **Обычный хостинг / VPS**: скопируйте содержимое папки на сервер и отдавайте через nginx/Apache как статику. `api/server.js` разверните отдельным Node-процессом (например, через `pm2 start server.js`) и настройте nginx как reverse proxy на `/api/*`.
3. Backend можно также развернуть как serverless-функцию (Vercel Functions, Netlify Functions) — логика `POST /api/lead` переносится в обработчик почти без изменений.

## Как подключить домен

1. Купите домен (например, у reg.ru или другого регистратора).
2. В настройках домена добавьте A-запись, указывающую на IP хостинга, либо CNAME на адрес, который выдаст Vercel/Netlify при подключении домена в их панели.
3. Дождитесь обновления DNS (обычно от нескольких минут до 24 часов).
4. Обновите `https://chproject.ru` на реальный домен в `build.py` (или прямо в HTML) и пересоберите/загрузите файлы.

## Как подключить Яндекс.Метрику

1. Создайте счётчик на metrika.yandex.ru, получите числовой ID.
2. Вставьте официальный код счётчика Метрики в `<head>` каждой страницы (или в шаблон `head()` в `build.py`, чтобы он попал сразу везде при пересборке).
3. Замените `window.YM_COUNTER_ID = 00000000;` в конце страницы (перед подключением `main.js`) на реальный ID.
4. В интерфейсе Метрики настройте цели по событиям, которые уже отправляются кодом: `calc_open`, `calc_update`, `calc_complete`, `phone_click`, `telegram_click`, `lead_submit`, `photo_upload`, `portfolio_view`, `portfolio_filter`, `ai_chat_open`.

## Как подключить Telegram для получения заявок

1. Создайте бота через @BotFather, получите `TELEGRAM_BOT_TOKEN`.
2. Узнайте `TELEGRAM_CHAT_ID` (свой личный чат с ботом или ID группы/канала для заявок).
3. Впишите оба значения в `.env` рядом с `api/server.js` (скопировав `.env.example`).
4. Запустите backend (`cd api && npm install && npm start`) — при новой заявке бот пришлёт сообщение с деталями.

## Что нужно сделать для запуска рекламы

1. Убедиться, что реальные телефон/Telegram и хотя бы часть реальных фото/цен уже на месте — так реклама не будет вести на заглушки.
2. Подключить Яндекс.Метрику и/или GA4 **до** запуска рекламы, чтобы не терять статистику первых дней.
3. Настроить цели (конверсии) в Метрике/Analytics на событие `lead_submit` — это конечная цель воронки.
4. Использовать UTM-метки в рекламных ссылках (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`) — они автоматически сохраняются и прикладываются к каждой заявке (см. `js/main.js`, `captureUTM`).
5. Проверить сайт на мобильном перед запуском — основной трафик с рекламы обычно идёт со смартфонов.

## Пересборка страниц после правок контента

Если меняете текст/структуру через `build_pages.py` / `content_blocks.py` / `build.py`:

```bash
cd chproject
python3 build.py
```

Скрипт перезапишет `.html`-файлы. Правки, сделанные вручную прямо в готовых `.html`, при пересборке будут потеряны — вносите такие правки либо в генератор, либо решите отказаться от build-скрипта и редактировать HTML напрямую (тоже нормальный путь для небольшого сайта).

## Telegram-бот для заявок

Бот присылает каждую заявку с сайта и позволяет вести её по статусам прямо в Telegram.

### Что умеет

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Список команд |
| `/leads` | Последние 10 заявок |
| `/new` | Только необработанные |
| `/today` | Заявки за сегодня |
| `/lead 12` | Открыть заявку №12 |
| `/stats` | Сколько всего, за сегодня, по статусам и источникам |

Под каждой заявкой — кнопки: **Взять в работу**, **Дозвонился**, **Сделка**, **Отказ**.
Нажатие меняет статус прямо в сообщении, а история сохраняется — видно, кто и когда менял.

### Как запустить (по шагам)

**ШАГ 1.** В Telegram найдите **@BotFather**, отправьте `/newbot`, придумайте имя.
В ответ придёт токен — длинная строка вида `12345678:AAE...`. Скопируйте её.

**ШАГ 2.** Найдите **@userinfobot**, напишите ему любое сообщение.
Он ответит вашим `Id` — это число и есть ваш `TELEGRAM_CHAT_ID`.

**ШАГ 3.** В папке `api` скопируйте файл `.env.example` и назовите копию `.env`.
Откройте её блокнотом и впишите:

```
TELEGRAM_BOT_TOKEN=сюда_токен_из_шага_1
TELEGRAM_CHAT_ID=сюда_число_из_шага_2
```

Сохраните файл.

**ШАГ 4.** Откройте терминал в папке `api` и выполните:

```bash
npm install
npm run all
```

Команда `npm run all` поднимает сразу и приём заявок с сайта, и бота.

**ШАГ 5.** Напишите своему боту в Telegram `/start`. Он ответит списком команд —
значит, всё работает. Оставьте тестовую заявку на сайте и проверьте, что она пришла.

### Если заявки должны приходить нескольким людям

В `TELEGRAM_CHAT_ID` можно указать несколько id через запятую:

```
TELEGRAM_CHAT_ID=123456789,987654321
```

Уведомления о новых заявках уходят на первый id в списке, а командами бота
могут пользоваться все перечисленные.

Можно также создать группу, добавить туда бота, сделать его администратором
и указать id группы (он начинается с минуса, например `-1001234567890`).

### Где хранятся заявки

Файл `api/leads.json`. Обычный текстовый файл — можно открыть и прочитать.
Он защищён `.gitignore`, чтобы телефоны клиентов не попали в репозиторий.
Делайте резервную копию этого файла.

### Важно про безопасность

Токен бота лежит только в `api/.env` и никогда не попадает на сайт —
посетители его увидеть не могут. Файл `.env` не публикуется в репозитории.
Если токен всё же куда-то утёк — отправьте `/revoke` боту @BotFather
и получите новый.
