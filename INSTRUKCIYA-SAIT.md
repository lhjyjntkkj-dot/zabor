# Как запустить сайт CH PROJECT на своём компьютере

Инструкция для тех, кто раньше этого не делал. Занимает 10 минут.

---

## Важно понять сразу

**Файл `index.html` нельзя просто открыть двойным кликом.**
Сайт откроется, но без оформления — голый текст без стилей и кнопок.
Так происходит потому, что сайту нужен настоящий веб-сервер.

Не переживайте: сервер уже подготовлен, запускается одним файлом.

---

## ШАГ 1. Установите Node.js

Это программа, на которой работает сервер сайта. Ставится один раз.

1. Откройте **https://nodejs.org**
2. Нажмите большую зелёную кнопку слева — на ней написано **LTS**.
3. Откройте скачанный файл, жмите «Далее» до конца установки.
4. **Перезагрузите компьютер** (иначе система может не увидеть программу).

**Проверка, что установилось:**

- **Windows:** нажмите `Win + R`, напишите `cmd`, нажмите Enter.
- **Mac:** откройте программу «Терминал» (через поиск Spotlight).

В чёрном окне напишите и нажмите Enter:

```
node -v
```

Должна появиться версия, например `v22.11.0`. Появилась — идём дальше.

---

## ШАГ 2. Распакуйте сайт

1. Скачайте архив `chproject-site.zip`.
2. **Распакуйте его** (правой кнопкой → «Извлечь всё»).
   Работать прямо внутри архива нельзя.
3. Положите папку в удобное место, например на рабочий стол.

Внутри должны быть файлы `index.html`, `start-site.js`, папки `css`, `js`, `api`.

---

## ШАГ 3. Запустите сайт

**Windows:** дважды щёлкните файл **`ЗАПУСТИТЬ САЙТ.bat`**

**Mac:** дважды щёлкните **`ЗАПУСТИТЬ САЙТ.command`**

> Mac может сказать «не удалось открыть, неизвестный разработчик».
> Тогда: правой кнопкой по файлу → «Открыть» → в окне ещё раз «Открыть».

Откроется чёрное окно, в нём появится:

```
  ✅ Сайт CH PROJECT запущен

  Откройте в браузере:  http://localhost:8080
```

**Это окно закрывать нельзя** — пока оно открыто, сайт работает.

---

## ШАГ 4. Откройте сайт

Откройте браузер и введите в адресную строку:

```
localhost:8080
```

Откроется ваш сайт — полностью рабочий, как в интернете.
Можно ходить по страницам, проходить квиз, проверять вид на телефоне.

**Чтобы остановить сайт:** в чёрном окне нажмите `Ctrl + C`, либо просто
закройте окно.

---

## ШАГ 5. Включите приём заявок (если нужно проверить квиз)

Сайт сейчас работает, но заявки из квиза никуда не уходят — за них
отвечает отдельная программа. Если хотите проверить квиз целиком:

1. Откройте папку `api` внутри сайта.
2. **Windows:** дважды щёлкните **`ЗАПУСТИТЬ ПРИЁМ ЗАЯВОК.bat`**
   **Mac:** дважды щёлкните **`ЗАПУСТИТЬ ПРИЁМ ЗАЯВОК.command`**

При первом запуске он минуту поставит нужное, потом напишет:

```
CH PROJECT lead API — порт 3001
🤖 Бот CH PROJECT запущен.
```

**Теперь открыто два чёрных окна** — это нормально. Одно держит сайт,
второе принимает заявки. Оба должны быть открыты.

Если вы уже настроили Telegram-бота (файл `.env` на месте) — заявки
придут вам в Telegram. Если нет — просто сохранятся в файл
`api/leads.json`, это тоже нормально для проверки.

---

## Проверьте, что всё работает

1. Откройте `localhost:8080`
2. Пройдите квиз до конца, введите имя и телефон.
3. Должен появиться экран «Спасибо! Заявка принята».
4. Проверьте Telegram (если бот настроен) или откройте файл
   `api/leads.json` Блокнотом — заявка должна быть там.

---

## Как посмотреть, как сайт выглядит на телефоне

Не обязательно брать телефон в руки:

1. На открытом сайте нажмите `F12` (на Mac: `Cmd + Option + I`).
2. Нажмите значок телефона/планшета в появившейся панели
   (или `Ctrl + Shift + M`).
3. Сверху выберите модель, например iPhone.

Так вы увидите сайт глазами клиента с телефона — а это большинство
ваших посетителей.

### Открыть на настоящем телефоне

Можно, если телефон и компьютер в одной Wi-Fi сети:

1. Узнайте адрес компьютера в сети:
   - **Windows:** в чёрном окне напишите `ipconfig`, найдите строку
     «IPv4-адрес», например `192.168.1.5`
   - **Mac:** «Системные настройки» → Wi-Fi → «Подробности», там будет
     IP-адрес.
2. На телефоне откройте браузер и введите этот адрес с портом:

   ```
   192.168.1.5:8080
   ```

## Если что-то пошло не так

**Чёрное окно мигнуло и закрылось**

Node.js не установлен или компьютер не перезагружен после установки.
Вернитесь к шагу 1.

**«node» не является внутренней или внешней командой**

То же самое: Node.js не видно системе. Переустановите и перезагрузитесь.

**Написано «Порт 8080 уже занят»**

Сайт уже запущен в другом окне — закройте лишнее. Либо порт занят другой
программой: тогда откройте `start-site.js` Блокнотом и в строке

```js
const PORT = process.env.SITE_PORT || 8080;
```

замените `8080` на `8081`. Сохраните и запускайте заново, а в браузере
открывайте `localhost:8081`.

**Сайт открылся, но выглядит как голый текст без оформления**

Вы открыли `index.html` двойным кликом. Так нельзя — закройте вкладку,
запустите `ЗАПУСТИТЬ САЙТ` и откройте `localhost:8080`.

**При отправке заявки: «Сервер приёма заявок не запущен»**

Вы не сделали шаг 5. Запустите `ЗАПУСТИТЬ ПРИЁМ ЗАЯВОК` в папке `api`.

**Изменил файл, а на сайте по-старому**

Нажмите `Ctrl + F5` (на Mac `Cmd + Shift + R`) — браузер перезагрузит
страницу начисто.

## Если правите тексты сайта

Страницы `index.html`, `zabory.html` и другие **собираются автоматически**
из файлов `build_pages.py` и `content_blocks.py`. Если вы отредактируете
`index.html` напрямую, правки пропадут при следующей пересборке.

Правильный порядок: изменить текст в `build_pages.py` → в чёрном окне
выполнить

```
python3 build.py
```

→ обновить страницу в браузере.

Для этого нужен установленный Python. Если не планируете править
структуру — можно не устанавливать.

---

## Что дальше

Пока сайт работает только на вашем компьютере: по адресу `localhost:8080`
его видите только вы. Чтобы сайт открывался у клиентов из интернета,
нужен хостинг и домен — это отдельный шаг, напишите, когда до него
дойдёте.

Перед публикацией не забудьте заменить заглушки: телефон
`+7 000 000-00-00`, пустые ссылки на Telegram и ВКонтакте,
демонстрационные фото.
